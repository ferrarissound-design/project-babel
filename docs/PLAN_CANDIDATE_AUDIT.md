# 候補の脱落段階の診断計画

2026-11-22。PR #29 の次の診断として、実装・測定前に手順を固定する。
既知の PUD 19 言語と、すでに調査済みのガリシア語を別集計する。
新しい解読器の採用試験でも、初見言語の評価でもない。

## 入力と集計

- UD r2.15、英語の構造化対訳、換字・清掃、100% 対訳と一文ずらした対照は clause_probe と同じ。
- 標準設定の最初の対応付けだけを追跡し、置換対照の再学習は省く（`v16_gates=False`）。解読器本体は変更しない。
- 元の対象文にある VERB と、その直接の `nsubj`・`obj` の組を採点用に列挙する。清掃で残った組と、元の組を分けて数える。
- 主な分母は、英語対訳に3役があり、対象の清掃後の語列に上記の組が少なくとも1組ある文。全対訳文・英語側3役あり・対象側の組ありも記録する。
- 各段階で、正解の主語・述語・目的語がそれぞれ1語以上候補にある文と、**同じ正解の組の3語**がそろう文を数える。

## 入れ子の段階

1. `units`: 各語に語幹単位が存在する。
2. `pos_allowed`: 推定品詞による制約で、その役割を持つ概念との対応が少なくとも1つ許される。
3. `positive_link`: 双方向 EM の積が正の対応がある。
4. `threshold`: 対応の強さが0.25以上。
5. `best_concept`: 語幹ごとの最良の概念にその役割が含まれる（解読器の最大値と同じ同点処理）。
6. `resolved_role`: 役割が一意、または学習した格接辞によって一意に絞れる。
7. `first_position`: 各役割で最初に選ばれた位置が残る。

各文について初めて正解候補がなくなった段階を記録する。役割別に候補が別の節に残る場合と、同じ組が残る場合を区別する。
役割が一意の概念だけを使う PR #29 の候補集合も**別集計**し、同 PR の結果と照合する。曖昧な概念を格接辞で解決する経路を、この集合で誤って除外しない。
最終位置から復元した票数・向きは解読器の実際の集計と照合する。

## 報告と限界

20言語×通常・ずらした対訳の40条件を言語別に保存し、入力ハッシュ、実効設定、段階別の数、最初の脱落段階、文ごとの追跡を残す。
リポジトリには集計値と日本語の既報3文の例を保存する。全対訳文の詳細は `--details-out` でローカルに再生成できる（大きいためコミットしない）。
日本語の既報3文も追跡する。結果の良否による言語の除外や閾値調整はしない。
入力清掃は既存方式と同じで、UDの単語境界と除外品詞を利用する。清掃後の候補の絞り込みには対象側の注釈を使わず、採点時に参照する。同じ対象文の別の節の組でも正解候補と数えうるため、これは構造的な回収可能性であり、英語との訳義の一致や翻訳精度を表さない。
品詞制約の段階での脱落は、制約を外して再学習した場合の効果量ではない。清掃前から対象文自体が評価対象外になった例は、主な分母に含まれない。
