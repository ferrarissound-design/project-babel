# 事前登録: v1.5 動詞の位置の主張に証拠を要求する

この文書は、実装と測定の**前に**コミットする。採用の基準・評価用の言語・採点はここに書いたものだけを使い、結果を見てから変えない。

## 背景

実在言語（UD r2.15 を換字した 10 言語、`docs/REAL_LANGUAGES_RESULTS.md`）で、v1.4.0 の動詞の位置の主張は 5 件あり、正解 4・誤答 1 だった。しかし換字を戻して調べると、解読器が動詞とみなしたクラスの大半は動詞ではなかった（UD で VERB だった割合は 0.3〜5%。ウェールズ語のみ 34%）。正解 4 件は、10 言語中 9 言語で正解が medial であることによる偶然の一致（問題記録 #94）。また、形態の検定が「なし」でも接辞の側を主張することがあった（#96）。

追加の測定（設計のため。評価用の言語は見ていない）で、動詞とみなしたクラスの語幹への偏りは次のとおりだった。実効語幹数（トークンの語幹分布の 2^エントロピー）は、生成器の言語 12 件で 11.4〜30.8、トルコ語 1.8（`bir` が 83%）、アイルランド語 3.7、ウェールズ語 17.8、フィンランド語 27.4、スペイン語 33.4。偏りの条件はトルコ語・アイルランド語型の誤りを止められるが、語幹が多様な開放クラスの名詞・副詞が動詞とみなされるフィンランド語・スペイン語型は止められない。**対訳も数詞の算術もない条件で、動詞を意味なしに見つける根拠は今の解読器にない**。

## 変更（設定 `v15_gates`、既定 True。False で v1.4.0 と同じ出力）

- **V1 動詞の位置の証拠要件**: 動詞の位置の主張には、役割の分かる対訳による証拠（`self.aligner` が存在し、アラインメントで動詞の位置の票が 5 文以上ある）を要求する。証拠がなければ `verb_position.value` は保留にする。
  - 参考として、動詞とみなしたクラスの位置の統計を、主張とは別の項目 `verb_candidate_position`（値・割合・文数・「動詞であることの根拠はない」という注記）として出力する。採点の対象にしない。
- **V2 開放クラスの要件**: 動詞のクラスの候補に、トークンの語幹分布の実効語幹数が 8 以上であることを要求する（8 は、設計に使った生成器の言語の最小値 11.4 と、トルコ語 1.8・アイルランド語 3.7 の間に置いた）。満たさない候補は動詞の候補から外す。
- **M1 形態の判定の統一**（#96）: `null_gates` が有効なとき、`verdict.morphology.present` を「G1' の検定が接尾辞側か接頭辞側のどちらかで有意、かつ接辞が 3 種以上」に変える。従来の「接辞付きの割合 0.2 以上」の条件は外す。構造の主張（`affix_position`）は変えない。

他の関門（G1'〜G4'）と閾値は変えない。

### 採用の基準

- **A（動詞の位置の誤りの除去）**: 評価用の 10 言語で、v1.5.0 の `verb_position` の主張が 1 件以下。主張が出た場合、動詞とみなしたクラスの UD の VERB の割合が 0.5 以上でなければ、それは「偶然の一致」として誤りに数える。
- **B（接辞の側の維持）**: 評価用の 10 言語で、v1.5.0 の `affix_position` の判定（正解・誤答・保留）が v1.4.0 と同一。
- **C（合成言語での損失の報告）**: 開発シード 0〜19（3 系統 × LEVEL A・B・C、単語境界あり）で、`verb_position` の正解・誤答・保留を v1.4.0 と並べて報告する。**LEVEL A（対訳あり）では、正解が v1.4.0 の 95% 以上、誤答が v1.4.0 以下**であること。LEVEL B・C（対訳なし）の正解の減少は、設計上の結果として報告し、合否に含めない。
- **D（対照の維持）**: 開発シード 0〜19 の対照（random・shuffled・syllable）で、構造の主張が出た実行数が v1.4.0 と同一（関門を変えていないことの確認）。
- **E（形態の判定）**: 評価用の 10 言語の語を入れ替えた対照で、`morphology.present` が true になる言語が、v1.4.0 以下。

A・B は評価用の言語で1回だけ実行し、C・D は開発シードで判定する。C・D が不合格なら評価に進まず、設計の変更を新しい事前登録の修正として記録する。

### 併せて報告するもの（合否に含めない）

- 評価用の 10 言語での v1.4.0 の結果（比較用）。

## やらないこと

- 8（実効語幹数）・0.5・5 文などの閾値、評価用の言語の選択を、結果を見て変えない。
- 結果を見て解読器を調整しない。評価で A が不合格だった場合も、閾値は変えずに結果を記録する。

## 限界（事前に書く）

- V1 は、誤答を消すために主張を保留に変える変更でもある。LEVEL B・C の合成言語では、動詞の位置の正解も失う。
- V2 は、フィンランド語・スペイン語型（語幹が多様な開放クラスの名詞・副詞）の誤りを止めない。V1 がその場合の主張を止める。
- 対訳があるときに、アラインメントによる動詞の位置の票が動詞を正しく見つけているかは、実在言語では評価できない（UD に対訳がない）。LEVEL A の合成言語の結果でしか測れない。

## 開発シードでの判定（基準 C・D。開発シード 0〜19、`results/gates/gates-dev15.json`）

動詞の位置（単語境界あり、3 系統 × 20 シード = 各水準 60 件）:

| 水準 | v1.4.0 正解 / 誤答 / 保留 | v1.5.0 正解 / 誤答 / 保留 |
|---|---|---|
| A（対訳あり） | 56 / 3 / 1 | 56 / 2 / 2 |
| B（対訳なし） | 55 / 2 / 3 | 0 / 0 / 60 |
| C（対訳なし） | 55 / 2 / 3 | 0 / 0 / 60 |

- **基準 C: 合格**。LEVEL A の正解は 56（v1.4.0 の 100%）、誤答は 2（v1.4.0 は 3）。
- LEVEL B・C は、設計どおり全件保留になった。**失った正解は 110 件**（A・B・C の合計で、単語境界ありの全項目の正解は 635 → 526、誤答は 9 → 3）。これは合否に含めないが、v1.5.0 の代償として明記する。生成器の言語では、v1.4.0 の動詞の位置の主張の約 95〜97% が正解だった（55/57、56/59）ので、合成言語だけで見ると、この変更は性能を下げている。
- **基準 D: 合格**。対照（random・shuffled・syllable）の構造の主張が出た実行は、v1.4.0・v1.5.0 とも 0 / 20 で同一。
- 接辞の側は、単語境界ありの 180 件すべてで正解のまま（v1.4.0 と同一）。
- 単語境界なしは、正解 27 → 26、誤答 6 → 6。1 件の違いは V2（開放クラスの要件）による。
- 以上により、評価用の言語（基準 A・B・E）を1回だけ実行する。

## 評価用の 10 言語での1回だけの実行（`results/real_languages/real-languages-heldout.json`）

10 言語すべて取得できた（除外なし）。各 1000 文。

| | v1.4.0 | v1.5.0 |
|---|---|---|
| 動詞の位置（正解 / 誤答 / 保留） | 2 / 0 / 8 | 0 / 0 / 10 |
| 接辞の側（正解 / 誤答 / 保留） | 9 / 1 / 0 | 9 / 1 / 0 |
| 語を入れ替えた対照で `morphology.present` が true | 0 / 10 | 0 / 10 |
| 実コーパスで `morphology.present` が true | 7 / 10 | 10 / 10 |

- **基準 A: 合格**。v1.5.0 の動詞の位置の主張は 0 件（上限 1 件）。ただし V1 により、証拠のない条件では常に 0 件になるので、この基準は設計上ほぼ自明に満たされる。
- **基準 B: 合格**。接辞の側の判定は、10 言語すべてで v1.4.0 と同一。
- **基準 E: 合格**。対照での形態の判定は 0 / 10 で、v1.4.0 以下。
- 誤答の 1 件は、ペルシア語（正解 `both`: 接尾辞側 72%・接頭辞側 28%、解読器は `suffix`）。v1.4.0 も同じ。正解の閾値（75%）の境界の近くで、解読器の答えは優勢な側と一致している（#97）。

### v1.4.0 の動詞の位置の 2 件（比較。事前登録の外の診断）

| 言語 | 動詞とみなしたクラス（UD の品詞） | 判定 |
|---|---|---|
| ドイツ語 | **VERB 0%**、CCONJ 83%・SCONJ 14% | 正解（偶然の一致） |
| ポーランド語 | **VERB 96%** | 正解（本物の動詞のクラス） |

- ドイツ語は、先の 10 言語と同じ型の偶然の一致で、V2（開放クラスの要件）により、動詞のクラスが外れた。
- ポーランド語では、v1.4.0 は本物の動詞のクラスを見つけていた。v1.5.0 の V1 は、これも保留にする（代償）。その位置の統計は `verb_candidate_position`（medial）として残る。
- 先の 10 言語と合わせた 20 言語で、v1.4.0 の動詞の位置の主張は 7 件。うち動詞のクラスが本物だったのはポーランド語 1 件（ウェールズ語は 34%）で、残りは偶然の一致か、誤答だった。

### 限界

- V1 は、証拠がなければ常に保留にする。本物の動詞のクラスを見つけても、対訳なしでは区別できないため。
- 言語は 20 のみ。ポーランド語のように、動詞のクラスが正しく見つかる条件（屈折が豊かで、動詞が各文に 1 回出る）がどこまで一般的かは、この評価では分からない。
