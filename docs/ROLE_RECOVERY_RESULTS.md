# PROJECT BABEL：候補回収の改善実験と独立検証の状況

登録した採用条件を満たす改善の証拠は得られなかった。標準方式Aを維持する。

[事前登録](PREREG_ROLE_RECOVERY.md)に従い、品詞制約の軟化B、証拠に応じた閾値C、3役の共同推定D、複数候補と保留を組み合わせたEを、現行再現Aと比較した。これは実験用の3役推論部品であり、標準解読器の既定動作は変更していない。

## 1. 根本原因と評価の境界

推定品詞との衝突を完全に禁止すると誤ったクラス推定を後から回復できない。双方向事後確率の積に対する固定0.25は、長い文・不完全な主節対訳・低頻度語で拡散した対応を強く除外する。また、役割ごとの先行位置の選択は反復語や別の節を混ぜうる。候補の追加だけでは、この識別問題の解決を示さない。

PUDの英語記事単位で開発70%・最終30%を固定し、20言語の同じ記事を同じ側に置いた。各分割の対訳の中で再学習するtransductive比較であり、学習済み語彙の未知文への帰納的転移ではない。全PUDは既に調査した既知資料で、新しい独立初見評価ではない。語境界とUD品詞による入力清掃は既存方式を引き継ぐ。

以前の10/3,864は全文を一緒に学習した診断である。今回の各分割の結果とは分母と学習資料が異なるため、10件との差を改善量として扱わず、同一入力のAと比較する。UDの直接nsubj–VERB–objの一致は構造的一致で、英語主節との訳義一致を保証しない。

## 2. 実装した方式

| 方式 | 変更 |
|---|---|
| A | 硬い品詞制約、0.25、最良概念、格接辞解決、先行位置を再現 |
| B | 品詞の衝突を重み0.2とする双方向EMで再学習。閾値・選択はA |
| C | 独立文書の支持dと対応割合qからr=min(1,d/3)q、閾値0.25−0.20r |
| D | 各役割上位5位置から、強度の積/(1+範囲長)最大の異なる3位置を選択 |
| E | B+Cと共同推定。上位5組内の比0.8以上、各対応3文書以上の支持がある時だけ主張 |

Cの証拠指標とEの0.8は較正済みの正解確率ではない。誤対応での主張・高代理信頼度の誤答を直接数える。A/B/Cの実際の先行位置選択は、比較用の上位5候補への切り詰めでは変更しない。

## 6. 独立ブラインドテスト

**未実施**。現存のexternal/inbox全10件は過去の予測があり、新しい未見の第三者資料は提供されていない。PUDの予測は採点前にファイルとハッシュを固定したが、既に公開・調査済みの注釈なので独立ブラインド試験とは呼ばない。過去の修正版を初回結果として扱ったり、開発中にAIが自作した言語で代用したりしていない。

## 7. 未解決の問題

候補の量、1組を正しく選ぶ能力、不確実性を認めて保留する能力は別々である。低頻度語、複数節、英語主節と対象側の意味対応、推定品詞の誤りを同時に解消できたとは示していない。代理信頼度は較正済み確率ではなく、小さい分割の出力件数や換字seed間の変動も残る。全PUDで既知の失敗を踏まえた設計なので、この記事分離だけで未知言語への一般化を証明できない。

## 8. 次に優先する研究

最優先は、英語主節と対象側の同じ意味の節・役割を独立に注釈した資料を用意し、語彙対応と節の取り違えを分けて測ること。その資料の正解公開前に予測とハッシュを固定し、候補集合の回収率に加えて1組の出力適合率と誤対応への保留を検証する。合格・不合格の両方を、結果を見た閾値の再調整で置き換えず記録として保持する。
