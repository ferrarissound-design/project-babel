# 修正版の実在19言語再測定と述語の対応付け

対象は PR #27 の 6a43cf3、UD r2.15。評価済み19言語の原データと英語の原データは、前回記録した SHA-256 と一致した。前回と同じ構造化対訳を入力し、対訳が作れる全ての文に正しい訳を与える条件と、訳を1文ずつずらす対照条件で再実行した。正解となる品詞・依存関係は解読器に渡さず、予測後の照合に使った。

動詞位置は2正解・0誤答・17保留。正解はスペイン語とインドネシア語。ずらした対照では全19言語で動詞位置を保留した。全38実行で、動詞位置と主語・目的語の順序の予測値・証拠数、および動詞相対位置の検定記録（実票、対照の最大票、丸めたp値、通過判定）が保存済みの結果と一致した。

## 日本語の3票

652件の英語対訳から、125文で日本語の述語候補が出た。品詞の内訳で最も多いのは名詞50、次が動詞49。3役がそろったのは次の3文。

| PUD文ID | 英語の述語 | 選んだ日本語 | 選んだ主語 / 目的語 | 読み取れること |
|---|---|---|---|---|
| n01052006 | describe | 礎（名詞） | 彼 / 彼女 | この文の主動詞は「称し」。別の節の「礎」を選んでも末尾に1票入った。 |
| n01087035 | love | 大好き（形容詞） | 私 / トロピカル | 意味は対応するが、日本語では形容詞。「トロピカル」はカラーを修飾する。 |
| w02011029 | declare | 宣言（動詞） | 私 / オリンピック | 動詞は対応したが、UDで目的語の中心は「閉会」。 |

3票とも述語候補は主語候補・目的語候補より後ろだった。対照の最大は1票、二項検定は p=0.03704。票数とp値の両方が基準に届かない。UDで主語と目的語を持つ日本語動詞369件は全て両者より後ろで、集計した語順の向きだけでは個々の対応ミスに気付けない。

### 日本語で品詞による対応制限を外す試験

候補の範囲を広げると取りこぼしが減るかを調べた。位置判定の基準は同じ。

| 設定 | 述語候補の文 | うちVERB | 投票した文 | うちVERB |
|---|---:|---:|---:|---:|
| 現行 | 125 | 49 | 3 | 1 |
| 品詞制限なし | 125 | 49 | 3 | 1 |

品詞制限なしでの動詞位置は 保留。日本語1言語での探索として記録する。

## 再現方法

Pythonのハッシュシードを固定して実行する。次のコマンドは入力取得後、予測、各票、選んだ表層語とUD品詞をJSONに出す。データは各ツリーバンクのライセンスに従う。

```sh
PYTHONHASHSEED=0 python -m babel.experiments.predicate_trace ja_pud
PYTHONHASHSEED=0 python -m babel.experiments.predicate_trace ja_pud --no-pos-constraint
PYTHONHASHSEED=0 python -m babel.experiments.predicate_trace gl_pud
PYTHONHASHSEED=0 python -m babel.experiments.predicate_trace gl_pud --mismatch
```
