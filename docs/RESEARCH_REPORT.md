## 10. 研究上の限界

- 生成器と解読器を同じAIが設計した。解読器の事前仮定（接辞は閉じたクラス、会計文書に合計行がある、対訳は役割つきの構造で与えられる等）は生成器の設計と一致しており、内部テストの成績は完全な未知言語への一般化を証明しない。
- 独立した初見テストは、第三者が作った未知言語コーパスが投入されるまで未評価である。同じAIが解読器凍結後に作った第4系統は「準初見」であり、独立テストの代わりにはならない。
- LEVEL C で意味の過剰主張が0件なのは、解読器に意味ラベルの供給源がないという構造上の帰結である。「主張を我慢できた」ことの証明としては弱い。
- LEVEL C の数詞の値は「最小の単位を1とする」仮定つきの相対値である。合計行のないコーパスでは数詞の値は判定不能になる。
- 意味の正解は生成器の概念語彙（約150概念）との一致で測っている。実在言語の多義性・比喩・文脈依存は再現していない。同音異義語は語義の区別をせず、頻度の高い方を答える。
- 主語と目的語の順序、形容詞と名詞の順序は、役割の分かる対訳がなければ判定不能と報告する（LEVEL B・C では常に未回答）。
- 不規則動詞（補充形）は規則形と結び付けられない。SOT の「数詞の後は属格複数」という規則は、格語尾の機能推定を誤らせる。
- 単語境界のない連続書記では、全文書をまとめて分割する（train と held-out を分けていない）。
- 解読器の閾値（主張の閾値0.5、接辞の妥当性条件など）は開発シード0〜4で調整した。評価シード100〜119は最終実行まで使っていない。
- 外部LLM・有料APIは使っていない。Python 標準ライブラリのみ。実験は GitHub Actions とローカルコンテナの両方で実行し、出力ハッシュを比較する。
