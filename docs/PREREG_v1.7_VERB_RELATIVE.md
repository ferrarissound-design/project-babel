# 事前登録: v1.7 動詞の位置を、主語・目的語との前後関係で測る

この文書は、実装と評価用データでの測定の**前に**コミットする。採用の基準・評価用データ・採点は、ここに書いたものだけを使い、結果を見てから変えない。

## 背景

- 解読器の動詞の位置は、動詞が**文の中のどこにあるか**（文頭・文中・文末）を数えている。語順の類型論でいう動詞の位置は、動詞が**主語・目的語に対してどこにあるか**（SOV なら動詞は主語と目的語のあと）で決まる。
- 実在言語では、この2つがずれる。日本語・韓国語・ヒンディー語・トルコ語は動詞が主語・目的語のあとに来る（動詞末尾型）が、動詞のあとに助動詞や終助詞が付くので、「文の中の位置」は文中になる（問題記録 #95）。正解の定義（品詞 VERB が1つの文での位置）が `medial` ばかりになり、評価が単純な方法と区別できなかった（#101）。
- v1.6.0 は、実在言語で動詞の位置をすべて保留にする。解読器は、対訳で述語・主語・目的語の位置がそろって分かる文を、すでに持っている（語順の票の数え上げ）。

## 変更（設定 `v17_gates`、既定 True。False で v1.6.0 と同じ出力）

- **R1 動詞の位置を主語・目的語との前後関係で数える**: 対訳で述語・主語・目的語の3つの位置が分かる文（`pos_of` に `pred`・`head:subject`・`head:object` がある文）で、述語が両方より前なら `initial`、両方より後なら `final`、その間なら `medial` と数える（`order_counts["verb_rel"]`）。文の長さの条件は付けない（3つの位置が分かれば足りる）。
- **R2 帰無対照**: v1.6.0 の対訳の帰無対照（入れ替え 19 回）で、`verb_rel` の票数も数える。本物の票数が、入れ替えた 19 回のすべてを上回り、かつ 5 票以上のとき、`verb_position` を `verb_rel` の票の最多の値で主張する（信頼度 = 最多の割合 × min(1, 票数/20)）。
- 満たさないときは、従来（v1.6.0）の経路（動詞とみなしたクラスの位置と、A1 の関門）に戻す。

他の関門・閾値は変えない。

## 正解（実在言語）

対象の言語の PUD の注釈から機械的に作る。品詞 `VERB` の語で、子に `nsubj` と `obj`（受動の `nsubj:pass` は除く）の両方を持つものを数え、その語の位置（`id`）と、主語・目的語の位置を比べる。

- 動詞が主語・目的語の両方より前 → `initial`、両方より後 → `final`、その間 → `medial`。
- 最多の割合が **0.5 以上**ならその値が正解、未満なら「明確な正解なし」（採点から外す）。

（PUD の正解は、これまでの「文の中の位置」の定義とは別物になる。前の定義で測った評価の結果は、書き換えない。）

## やらないこと

- 5 票・19 回・0.5・p ≤ 0.05 などの閾値を、結果を見て変えない。
- 結果を見て解読器を調整しない。

## 限界（事前に書く）

- 動詞・主語・目的語の3つが対訳でそろう文は、全体の 3 割程度（PUD で 303/1000）。票が足りない言語は保留になる。
- 対訳は英語の文の注釈から作る。英語と対象の言語で、主語・目的語の対応が違う文がある。
- 正解の定義が解読器の定義と近くなったため、定義を揃えた効果と、解読器が本当に位置を言い当てた効果は、この評価では分けられない。
- 実在言語の評価用の言語は 5 つだけ。正解が `final` になる言語の数は、結果を見るまで分からない。
