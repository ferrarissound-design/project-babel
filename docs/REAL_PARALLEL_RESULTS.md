# 実在言語（PUD を換字）で、対訳があるときの評価の結果

事前登録: [PREREG_REAL_PARALLEL.md](PREREG_REAL_PARALLEL.md)。解読器 v1.5.0（凍結）。1回だけの実行。
データ: `results/real_parallel/real-parallel.json`（英語 PUD の SHA-256・各言語の SHA-256を含む）。再現: `python -m babel.experiments.real_parallel`。

## 1. 事前登録の結果

対象は 19 言語のうち **14 言語**。文字の種類が換字の記号数（82）を超えた 5 言語（ヒンディー語 83・タイ語 88・日本語 1577・韓国語 1000・中国語 2040）は、事前登録のとおり除外した。英語 PUD の 1000 文のうち、対訳を作れたのは 652 文（主語と目的語の両方があるのは 303 文）。

| 対訳の設定 | 動詞の位置（正 / 誤 / 保留） | 主語と目的語の順序（正 / 誤 / 保留） |
|---|---|---|
| 10% | 13 / 1 / 0 | 0 / 0 / 14 |
| 25% | 13 / 1 / 0 | 6 / 0 / 8 |
| 100% | 13 / 1 / 0 | **14 / 0 / 0** |
| 100%（対訳を 1 文ずつずらした対照） | 13 / 1 / 0 | 8 / 1 / 5 |

- 動詞の位置は、14 言語すべてが「文中」で、トルコ語（正解は「文末」）だけが誤答。
- 主語と目的語の順序は、100% で 14 言語すべてが `SO`（正解も 14 言語すべて `SO`）。

### 事前の予想との比較（外れたものは外れたと書く）

| 事前の予想 | 結果 |
|---|---|
| 10% では保留が多い | 主語と目的語の順序は予想どおり全件保留。**動詞の位置は外れた**（14 言語すべてが主張） |
| 100% でも、主張が出るのは半分以下の言語 | **外れた**（動詞の位置も主語と目的語の順序も、14 言語すべて） |
| 主張が出たものは、合成言語より誤答が増える | **外れた**（誤答は動詞の位置の 1 件、主語と目的語の順序は 0 件） |
| 誤対応の対照では、主張がほとんど出ない | **外れた**（動詞の位置は 14/14、主語と目的語の順序は 9/14 で主張が出た） |

## 2. 事後の分析（事前登録にない）

### 2.1 この評価は、成績を区別できない

- 正解の分布に偏りがある。動詞の位置は 13/14 が `medial`、主語と目的語の順序は 14/14 が `SO`。
- **常に `medial`、常に `SO` と答える単純な方法は、13/14 と 14/14 の正解になり、解読器と同じ**。つまり、この結果は、解読器が実在言語の語順を言い当てたことを示さない。
- PUD の言語は、ヨーロッパ・アラビア・トルコの言語で、ほぼ SVO か「動詞が文中」。ほかの語順（動詞が文末・文頭）を調べるには、別の言語セットが要る。

### 2.2 動詞の位置の主張は、対訳が対応していなくても変わらない

- 動詞の位置は、10%・25%・100%・ずらした対照のすべてで、14 言語が `medial`。
- チェコ語・スペイン語は、判定に使った文数（`n`）が設定によらず同じ（277・269）。つまり、対訳を使わない経路（動詞とみなしたクラスの位置）の主張で、対訳はまったく使われていない。残りの 12 言語は、対訳の票を使っているが、ずらした対照でも票数が 13〜35% しか減らない（例: アラビア語 230 → 191、フランス語 238 → 187、インドネシア語 267 → 174）。
- v1.5.0 の V1（対訳による証拠として、動詞の位置の票が 5 文以上）は、**対訳が文と対応していなくても満たされる**。V1 は、証拠の有無を見ているだけで、証拠が正しいかを確かめていない（問題記録 #100）。

### 2.3 主語と目的語の順序の票数は、対訳が対応しているときに大きく増える

| | 対訳が対応（100%） | ずらした対照 |
|---|---|---|
| 票数の範囲（14 言語） | 13〜92 | 0〜9 |
| 主張が出た言語 | 14 | 9（正解 8・誤答 1） |

- 票数は 10 倍違い、対訳の情報は使われている。しかし、現在の判定の下限（4 票）では、ずらした対照でも主張が出てしまう。
- 100% の票数の最小は 13（フィンランド語）で、ずらした対照の最大は 9。**票数の閾値（例: 10）で、この 14 言語は分離できた**。ただし、これは結果を見てから見つけた閾値で、同じデータで調整したことになる。使うなら、別のデータ（別の原文の言語など）で、事前登録して評価し直す必要がある。

## 3. 結論

- 対訳のある実在言語でも、v1.5.0 の動詞の位置の主張は、対訳の証拠によるものとは言えない（#100）。
- 主語と目的語の順序は、対訳がある程度（100%）あれば票が積み上がり、対応していない対訳との区別もつく。ただし、この評価では正解に偏りがあり、当たった意味を持たない。
- 次にやるなら、(1) 対訳の証拠を、対応した対訳とずらした対訳との比較で確かめる関門（このプロジェクトの帰無対照の考え方と同じ）、(2) 語順が多様な言語セットでの評価。どちらも新しい事前登録と別のデータが要る。

## 4. 限界

- 対訳は英語の文の注釈から作った見出し語の列で、対象の言語の文と構造が違うことがある。
- 正解は対象の言語の UD の注釈から作ったが、閾値（0.5・0.75）は事前登録のもの。
- 14 言語、2 項目のみ。
