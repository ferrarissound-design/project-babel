# 構造発見（babel/structure）: 意味を使わずに未知の記号列の規則を探す

このモジュールは翻訳しない。辞書・対訳・既知語を一切使わず、**記号の並びそのものから、偶然では説明しにくい規則性**を
探し、各仮説に根拠・反例・統計的な強さ・安定性・限界を付けて出す。規則が見つからないデータには「見つからなかった」と答える。
外部API・LLM・クラウドOCRは使わない（Python 標準ライブラリのみ。画像入力のときだけ OpenCV/NumPy）。

既存の解読器（`babel/decipher/`）・採点器・研究記録は変更していない。`babel/structure` は
`babel.generator`・`babel.evaluate`・`babel.structure_eval` を import しない（`tests/test_structure.py` で検査）。

## 使い方

```bash
# BABEL コーパス（documents[].sentences）、glyph-report.json、.txt のどれでもよい
python -m babel analyze corpus.json --out out/analysis.json          # out/analysis.md も書く

# 画像から直接（vision を内部で実行）。類似度を複数指定すると、先頭を主、残りを別の転写候補として比べる
python -m babel analyze page.png --out out/analysis.json --similarity 0.7,0.6,0.8 --region text:0,0,330,375

# 人が転写を訂正する（例は babel/structure/corpus.py の apply_corrections）
python -m babel analyze vision-output/glyph-report.json --out out/a.json --corrections fix.json --image page.png

# 別の転写候補（人の転写・別の設定）と比べる
python -m babel analyze t1.json --alt t2.json --alt t3.json --out out/a.json
```

訂正ファイルの例（位置は訂正前の転写の行番号・記号番号）:

```json
{"merge": [["g3", "g7"]],
 "split": [{"line": 2, "pos": 5, "into": ["g1", "g9"]}],
 "join": [{"line": 4, "pos": 0, "length": 2, "symbol": "g12"}],
 "substitute": [{"line": 0, "pos": 3, "symbol": "g5"}],
 "uncertain": [{"line": 7, "pos": 1}]}
```

入力に空白（単語区切り）があっても、解析には使わない。分割候補との一致率を参考として出すだけ。

## 出力（analysis.json / analysis.md）

| 項目 | 内容 |
|---|---|
| `statistics` | 行・記号の数、異なり、1回だけの記号、2〜8記号の反復、最長反復部分列、行頭・行末の共通部分、前後の文脈の多様さ、相対位置、共起、行と文書の類似度 |
| `global_tests` | コーパス全体が無作為な並びより規則的か（5検定、Holm 補正） |
| `hypotheses` | 多重検定を通った仮説。観測・根拠の位置（画像の座標を含む）・支持数・反例・p 値・標本と転写の安定性・他の方法との一致・**未検証の**解釈候補・限界・必要なデータ |
| `descriptive_observations` | 補正前は目立つが、偶然と区別できないもの（規則として扱わない） |
| `structures` | 置き換え可能に見える記号の集合、似た行のまとまりの固定部分と変わる部分 |
| `boundaries` | 単語境界の候補（5方式＋合議）、記述長、方式間の一致、部分標本での再現、境界ごとの票、圧縮の置換検定 |
| `detectability` | このデータ量で規則として検出されるのに必要な出現回数の目安 |
| `data_limits` / `review_points` | データ不足による制限、人が次に確認すべき箇所 |

**観測と解釈を分ける**: 例えば「記号 S が 13 行中 12 行の行頭にある」は観測。「文頭標識かもしれない」は
`interpretation.candidates` に、選べない候補の一つとして並ぶだけで、主張ではない。

## 方法

### 仮説の族と帰無モデル

| 族 | 統計量 | 帰無モデル |
|---|---|---|
| n-gram（2〜8記号の反復・連接） | Poisson 上側確率（期待値は行内シャッフルで解析的に計算） | 行内シャッフル（各行の記号の構成を保つ） |
| 行頭・行末（1〜3記号） | 同上 | 行内シャッフル |
| 一定間隔の反復（距離2〜8） | 同上 | 行内シャッフル |
| 共起（同じ行） | 超幾何の上側確率 | 各記号を含む行の数を保った独立配置 |
| 分散（各行に均等／少数の行に集中） | 含む行の数（置換分布で標準化） | 全体シャッフル（行の長さと頻度を保つ） |
| 置換可能性 | 直前・直後の文脈の残差ベクトルのコサイン（標準化） | 行内シャッフル |
| 行の類似 | 共有する2〜4記号列の数（標準化） | 全体シャッフル |
| 接辞（分割候補の語の端） | 別の形とも現れる語幹の数（標準化） | 語の型ごとの並べ替え |

行内シャッフルを帰無にするので、**記号の頻度の偏り（Zipf 分布）や行ごとの記号の偏りだけでは有意にならない**。

### 多重検定
族ごとに Westfall–Young の single-step maxT（全仮説の最大統計量の置換分布）で族単位の誤り率を制御し、
さらに族の数（8）で Bonferroni 補正する（族ごとの閾値 0.05/8）。大域検定5種は Holm。
支持する観測が最小数（n-gram 2、他は3）に満たないものは、有意でも記述的観察に回す。

### 安定性（二種類を分けて測る）
- **標本の揺れ**: 行の 70% を非復元抽出した部分標本で、同じ仮説が再び多重検定を通るか（復元抽出は行の重複が反復を作るので使わない）
- **転写の誤差**: 転写の 5% に誤分類・分割・結合を起こしても通るか。画像由来で形状の一致度が低い記号は3倍選ばれやすくする
- 段階: A = 両方 0.5 以上かつ別の方法とも一致、B = 両方 0.5 以上、C = それ以外（暫定）。接辞は分割に依存するので常に C
- `--alt` や画像の類似度の複数指定では、画像上の位置が重なるかで同じ仮説かを照合し、`stability.across_transcriptions` に入れる

### 単語境界
transition（既存 BABEL の遷移確率法）・unigram（既存 BABEL の分割）・branching（分岐エントロピー）・
mdl（記述長の利得による結合）・repeats（極大反復の両端）と、その過半数の合議。どれも正解とせず、共通の記述長で並べ、
方式間の一致と部分標本での再現を付ける。MDL 分割の圧縮率が行内シャッフルでも同じように得られるなら、
「境界の統計的根拠は弱い」と表示する。

### 短いコーパス
30行以下または600記号以下を短いコーパスとして扱い、高次の統計（語順・条件付きエントロピー）は記述のみにする。
置換回数は小さいコーパスほど多くする（≤800記号で 999 回）。
