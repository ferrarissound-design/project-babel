# 動詞のクラスの検証の探索（問題記録 #94・#98・#99）

v1.5.0 は、対訳のない条件で動詞の位置を主張しない（V1）。ポーランド語のように本物の動詞のクラスを見つけた場合も保留になる（#98）。この探索では、選ばれたクラスが本物の動詞かを、意味を使わずに見分ける手がかりがあるかを調べた。

**結論: 見分けるルールは作らなかった。問題は検証の段階ではなく、その手前の語形のクラス分けにある。**

再現: `python -m babel.experiments.verb_class_features`（`results/verb_class/features-dev.json`）。使ったデータ（実在言語 20 と合成言語の開発シード 0〜4）は、すでに結果を見た開発用のもの。品詞は採点・診断のためだけに使い、解読器には渡していない。

## 1. 語形のクラス（パラダイムのグループ）の品詞の純度

純度は、各グループで最も多い品詞の割合を、トークン数で重み付けして平均したもの。

| | コーパス数 | 純度の平均 |
|---|---|---|
| 合成言語（3 系統 × 5 シード、LEVEL C） | 15 | **0.967** |
| 実在言語（UD r2.15 を換字） | 20 | **0.548** |

- 合成言語では、動詞のグループ（動詞 97〜100%）と名詞のグループがきれいに分かれる。
- 実在言語では、語幹が数百〜1281 個ある巨大なグループが1つでき、品詞が混ざる（例: チェコ語は語幹 1281・トークンの 57%、動詞は 5.5%）。
- 「語幹が十分に多く、動詞が大半」のグループがあったのは、ポーランド語（語幹 51、動詞 98.9%）だけだった。動詞が 70〜90% のグループは、フィンランド語（語幹 14）・アイルランド語（9）・ウォロフ語（11、68%）などにあるが小さい。ペルシア語の 65%（語幹 163）は「各文に1回」の条件（0.41）で候補から外れていた。

## 2. 選ばれたクラスの特徴量（参考）

動詞の候補（語幹 4 以上、文の 30% 以上に出る）のうち、選ばれたクラスは、実在言語で 7 件（本物はポーランド語の 1 件）。特徴量（語幹の偏り・位置のエントロピー・接辞のない語の割合・語の長さ・隣の語の多様さなど）を並べたが、合成言語の動詞とポーランド語の動詞を、他の 6 件から一貫して分ける量は見つからなかった。例えば、接辞のない語の割合は、合成言語の動詞が 0.0、ポーランド語が 0.43、誤って選ばれたスペイン語のクラスが 0.04。

本物が 1 件しかないので、これを分けるルールを作れば過剰適合になる。作らない。

## 3. 解釈

- v1.5.0 の V1（証拠がなければ保留）は、この結果と整合する。実在言語では、動詞の位置を測る前提の「動詞のクラス」がほとんどの言語で存在しない。
- 生成器の言語は、品詞ごとに接辞の集合がはっきり分かれる（純度 0.97）。実在の言語は、品詞の間で接辞を共有し（格語尾と動詞語尾の同形、派生）、語幹も品詞をまたぐ。今のクラス分け（共有する基体の数で接辞を併合する union-find）は、これを前提にしていない。内部テストでこの問題が見えなかったのは、生成器が同じ前提で作られていたため（限界の1行目と同じ構図）。
- 次に直すべきは、クラス分けそのもの（#99）。品詞の純度は、意味の正解なしに測れないが、実在言語の UD の注釈を使えば中間の指標として評価できる。

## 4. 限界

- 品詞の純度は UD の品詞の体系に依存する（AUX と VERB、DET と PRON の区別など）。
- 合成言語は LEVEL C の開発シード 0〜4 のみ。
