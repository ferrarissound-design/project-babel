# v1.2 → v1.8 のまとめ: 解読器に自分を疑わせる

v1.2.0 から v1.8.0 までの 7 回の変更と、外部データでの 5 回の評価をまとめる。数値はすべて、各事前登録の文書と `results/` の結果ファイルから取った（出典は各節に書く）。

## 結論

1. **「分からないときに黙る」は、かなり確実になった。** 無作為なデータ・語順を壊したデータ・文と対応しない対訳のどれでも、構造の主張をほぼ出さない（v1.3〜v1.6）。
2. **実在言語で「分かる」ことは、ほとんど増えていない。** 実在言語で通用したのは、接辞の側（20 言語で 17 正解・1 誤答・2 保留）だけ。動詞の位置は、v1.8.0 では実在言語のほぼすべてで保留になる。
3. **内部テストで見えなかった問題の多くは、生成器と解読器が同じ前提で作られていたことから来ていた。** 外部データ（同じAIが設計していない言語）に当てて初めて見えた。

## 3. 分かったこと

### 3.1 自分を疑う手順は、重ねて使うと効く

関門は、どれも「本物のデータと、構造を壊した対照を比べ、区別できなければ黙る」という同じ形をしている。壊し方を変えて重ねた。

- **語を無作為にする**（v1.3）: 無作為な語列・音節列で、接辞を主張しない。
- **多重検定を補正する**（v1.4）: 2 つの検定のどちらかが通れば主張する、という作りは、偽陽性率を約 2 倍にしていた。
- **対訳を入れ替える**（v1.6）: 対訳が文と対応していなくても主張が変わらないなら、その主張は対訳に基づいていない。
- **票の割れ方を検定する**（v1.8）: 3 つの値に票がでたらめに散っても、どれかが最多になる。

### 3.2 生成器と解読器の共通の前提が、外部データで露呈した

| 前提 | 合成言語 | 実在言語 | 記録 |
|---|---|---|---|
| 品詞ごとに接辞の集合が分かれる | 語形のクラスの品詞の純度 0.967 | 0.548。巨大なクラスに品詞が混ざる | #99 |
| 動詞は「各文に1回出る、形が変わるクラス」 | 動詞のクラスが当たる | 限定詞・副詞・名詞のクラスが選ばれる（トルコ語は `bir` が 8 割） | #94 |
| 動詞の位置は「文の中の位置」で測れる | 動詞が文末なら文末に来る | 動詞のあとに助動詞が付き、文中になる（日本語・韓国語・ヒンディー語） | #95 |
| 対訳の経路はクラス分けを確かめる | 品詞の制約が正しいので、問題が見えない | 品詞の制約のせいで、対訳の述語が誤ったクラスに結び付く | #100 |

内部テストの成績が高かったのは、解読器が強かったからではなく、生成器が解読器と同じ前提で言語を作っていたからだった部分が大きい。研究の限界の1行目（「生成器と解読器を同じAIが設計した」）は、注意書きではなく、実際に成績を押し上げていた。

### 3.3 実在言語で通用したもの

- **接辞の側**: 対訳なしで、20 言語で 17 正解・1 誤答（ペルシア語、正解の閾値の境界）・2 保留。「常に接尾辞」と答える単純な方法より良い。
- **主語と目的語の順序**（対訳があるとき）: PUD の 19 言語で 19 正解。ただし正解がすべて SO で、単純な方法と区別できない。自然言語の約 9 割は SO なので、この偏りは評価のデータを変えても残る。

## 4. 分からないこと・できないこと

- **実在言語の動詞の位置**: v1.8.0 はほぼ保留にする。述語・主語・目的語の位置が対訳でそろう票が 6〜44 票と少なく、3 つの値の間で割れる。票を増やす（より大きい対訳データ）か、アラインメントの質を上げない限り、関門を調整しても答えは出ない。
- **実在言語の語彙（意味）の推定**: 評価していない。
- **単語境界のない文章の構造**: v1.3 以降、動詞の位置・接辞の側を常に保留にしている。分割の精度そのものは改善していない（#34）。
- **独立した初見テスト**: 第三者が作った未知言語コーパスでの評価は、2 件（`gpt6-blind-01` と `outsider-vso-prefix-7-v1`）あり、どちらも同じAIの系統（GPT-6）が作ったもの。

## 6. 次の課題

1. **アラインメントの質を上げる**: 実在言語でつまずく根本。英語の見出し語と対象の言語の語幹の結び付きが、頻出語どうしの偶然の一致に引っ張られる。
2. **より大きい対訳データ**: 述語・主語・目的語がそろう票が増えれば、v1.8 の二項検定を通る言語が増えるはず（予想）。
3. **語順が多様な言語**: 主語と目的語の順序を評価するには、OS 型の言語（自然言語では少ない）が要る。
4. **第三者の初見テスト**: 同じAIの系統が作っていない未知言語コーパス。
