# 事前登録：候補回収と、誤答・保留を含むA〜Eの比較

2026-11-23。実装・新しい測定の前にこの計画をコミットする。
作業ブランチは `research/role-recovery-validation`、基点はPR #30の `0180be30b6df159c564971a8d6bef707505fd511`。

## 現状分析と仮説

PR #27（main → fix/decipher-evidence-audit）は評価専用文書、対訳重複・競合、大票数の二項検定、版別設定を修正した。
#28 → #29 → #30は、その修正版を継ぐ追跡・診断で、標準の解読手法を変更していない。いずれも現在未マージ。
mainは `3c365c6`。この依存関係を維持し、main・既存PRを更新しない。

- `engine._pos_constraint` は推定N/Vと概念の役割が衝突すると対応を禁止する。推定品詞の誤りが回復不能になる（H1）。
- `align.Aligner` は双方向IBM Model 1の事後確率の**積**を使い、`_fit_alignment` は一律0.25以上だけを残す。長い対象文、英語主節だけの不完全な対訳、語形変化、低頻度語による確率の拡散が、正解と誤答の両方を弱めうる（H2）。
- 語幹ごとの最良概念を選び、`_count_orders` は役割ごとに `setdefault` で最初の位置を残す。反復語や複数節で先行位置を誤選択し、別の節の役割を組み合わせる（H3）。
- 英語の主節と対象言語の任意の直接nsubj–VERB–objは、意味的に対応するとは限らない。UD一致と翻訳精度を混同できない（H4）。

既知19言語の3,864適格文では、H1の段階で1,603文、閾値で2,235文、最初の位置で16文が3役の組を失い、10文だけが残った。
この観察は固定モデル内の診断であり、制約や閾値を変えた場合の改善量ではない。

## 比較方式：パラメータを結果から調整しない

標準エンジンから独立した、明示的に呼び出す実験用の3役推論部品を `babel/decipher/` に置く。
標準解読器の既定動作は維持する。推論部品にはJSON往復したpublicだけを渡し、注釈・採点器・生成器をimportさせない。

- **A**：現行の品詞制約、0.25、最良概念、格接辞による役割解決、最初の位置を正確に再現する対照。
- **B**：品詞で衝突する語幹→概念にも重み0.2、他には1を与える確率的事前重みで双方向EMを再学習する。接辞→概念は禁止のまま。閾値・位置選択はA。0.2は較正済みの正解確率ではない。
- **C**：硬い品詞制約はA。語幹と概念の独立文書での共起数dと、全対訳での対応強度に占めるその概念の割合qから、証拠指標 r=min(1,d/3)×q を作り、閾値を0.25−0.20r（下限0.05）とする。最良概念・位置選択はA。この指標を正解確率とは呼ばない。
- **D**：Aの役割解決後の候補から各役割上位5位置を保持する。異なる3位置の組を、対応強度の積/(1+最大位置−最小位置)で順位付けし、最高の1組を選ぶ。句読点や特定語順で除外しない。
- **E**：Bの軟らかい学習とCの閾値を併用し、最良の概念1つに限定せず役割と両立する複数候補を保持する。曖昧な概念は一意の格手がかりがある場合だけ役割を解決する。各役割上位5位置、上位5組を保持する。Dと同じ組スコアを使い、最上位組のスコア/上位5組のスコア和が0.8以上、かつ選んだ3語の各対応が独立した3文書以上に支持される場合だけ1組を主張し、それ以外は保留する。EはB/C/Dを合わせた方式であり、独立した一要因のアブレーションではない。

同点処理は明示的に固定する。Aは既存の文字列による最大値を維持する。新しい組の順位はスコア降順、位置の組の昇順。
全方式について生の候補と共通予算「各役割上位5位置」の回収率を別々に報告する。A/B/Cの実際の先行位置選択は、診断用の上位5への切り詰めでは変更しない。
Eの0.8も不確実性の代理指標で、経験的な誤答を数えて検証する。

## 実在言語の分離と実行

- UD r2.15の既知19言語＋調査済みガリシア語。原文・英語入力ハッシュを保存する。
- 英語の `newdoc id` ごとに、ニュースnと百科wを別々に固定文字列付きSHA-256で並べ、各群の先頭70%を開発、残り30%を最終比較にする。同じ記事の全言語・全文を同じ側に置く。対象側の係り受けを分割に使わない。分割台帳を測定前に固定する。
- **各分割の中だけ**で、与えられた対訳と対象文から学習してその分割を解読するtransductive比較。開発の学習済み語彙を未知文に移す帰納的評価ではない。分割間で記事・学習状態・対訳を共有しない。
- 通常対訳と、同じ分割内の採用対訳をちょうど1文ずらした対照。異なる分割間でずらさない。
- 換字シード0・1・2で、同じ文字集合の全単射を実際に変える。形態の反復を保つ。これは記号名・同点処理への頑健性であって、独立した3標本ではない。全方式は同じ入力・シードを使う。
- まず開発の全方式を測定して判定を保存し、コード・設定・開発結果のハッシュを固定してから最終比較を実行する。最終結果を見て方式・閾値を変えない。
- 全PUDは過去に見た既知データ。この記事分離を、独立初見検証として報告しない。
- 単語境界・UD品詞に基づく既存の清掃は引き継ぐ。生の文字資料に対する認識・単語分割の改善は測定しない。

## 指標と採点

各方式は最後に1組を出すか保留する。候補に正解が含まれただけで最終正解とは数えない。

1. **主要指標**：英語側に3役のある全文で、出力した組が対象のVERBと直接のnsubj・objの同じ組かを採点する。正解数、誤答数、保留数、適合率=正解/全出力、誤答率=誤答/全出力、保留率=保留/全対象文、正解/全対象文を報告する。対象側に正解組がない文への出力も誤答として数える。
2. **候補診断**：英語3役＋清掃後の対象側に正解組あり、を共通分母にした生/上位5の3役回収率、役割別回収率、候補位置数の平均・95百分位、候補組数、候補全体の構造的適合率を報告する。
3. **言語別**：上記を各言語と既知19言語の集計、ガリシア語で別表示する。換字シードは別表示し、同じ文を3件の独立標本として合算した有意性を主張しない。
4. **副次指標**：出力組の動詞の前/間/後の最多値について、5票以上かつ既存B1と同じ片側二項上側確率≤0.05/3なら語順を主張する共通規則で、正解・誤答・保留を比較する。これは19回の再学習を含む標準エンジンの最終判定全体ではない。
5. **対照**：誤対応の出力数と、代理信頼度0.8以上の誤答数を報告する。誤対応でも対象側の構造だけが偶然一致する場合があり、これを翻訳成功と呼ばない。
6. **時間**：共通の前処理、硬い/軟らかい学習、方式別の選択処理を分け、共通費用を含めた比較用の所要時間も記録する。時間以外の出力とハッシュを再実行で照合する。

推論結果をまずファイルへ固定しハッシュを記録してから採点する。PUDの注釈は既に公開・調査済みであり、この固定を新しい独立ブラインド試験とは呼ばない。

## 採用・不採用の基準

開発の既知19言語の各換字シードで、Aに比べて次のすべてを満たす方式だけを採用候補にする。

- 正解数がAより少なくとも3文多い。
- 誤答数がA以下で、出力適合率もA以上（Aが無出力なら適合率条件は比較不能として不合格）。
- 共通予算の候補3役回収数がAより多い。
- 誤対応の出力数と高代理信頼度の誤答数がA以下で、誤対応での語順の主張が0。
- 内部開発比較でも正解数を減らさず、誤答数・意味手がかりなしの主張数を増やさない。

候補が複数なら、各シードの最小適合率が最大、次に正解の増分の最小値が最大、次にB/C/D/Eの順で1つを開発時点に固定する。
その候補が最終比較でも同じ基準を満たし、ガリシア語で誤答数を増やさず、内部最終比較と標準機能の回帰検査にも合格した場合だけ、後続の標準統合を提案できる。
すべて不合格なら標準Aを維持する。最終比較は登録済みA〜Eすべてを測るが、最終結果で候補を選び直さない。
厳密な独立検証がないため、合格しても未知言語への一般化が実証されたとは報告しない。
