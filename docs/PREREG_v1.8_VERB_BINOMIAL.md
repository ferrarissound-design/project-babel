# 事前登録: v1.8 動詞の位置の主張に、最多の値の二項検定を要求する

この文書は、実装と評価用データでの測定の**前に**コミットする。採用の基準・評価用データ・採点は、ここに書いたものだけを使い、結果を見てから変えない。

## 背景

v1.7.0 は、対訳で述語・主語・目的語の位置がそろう文から、動詞の位置（主語・目的語との前後関係）を数える（R1）。本物の票数が入れ替えた対訳の票数を上回り、5 票以上なら、最多の値を主張する（R2）。実在言語（PUD、19 言語）では 11 正解・6 誤答（約 65%）だった（問題記録 #102）。

R2 は、最多の値の**割合**を見ていない。例えば、ヒンディー語は 20 票中 8 票（40%）、タイ語は 32 票中 13 票（41%）で主張した（前者は正解、後者は誤答）。3 つの値（`initial`・`medial`・`final`）に票がでたらめに散らばっても、どれかが最多になる。

## 変更（設定 `v18_gates`、既定 True。False で v1.7.0 と同じ出力）

- **B1 最多の値の二項検定**: R2 の条件に加えて、最多の値の票数 k が、票数 n のうちで、確率 1/3 の二項分布の上側確率 P(X ≥ k) ≤ **0.05 / 3**（3 つの値から最多を選ぶ分の Bonferroni 補正）であることを要求する。満たさなければ、R1 の主張をしない（v1.6.0 の経路に戻る）。

閾値（1/3、0.05/3）は、結果を見る前から決まる統計の基準で、データに合わせて選んでいない。

**事前に分かっていること**: この基準を、すでに見た PUD の結果に当てると、ヒンディー語（8/20、P = 0.34）・タイ語（13/32、P = 0.24）・中国語（6/8、P = 0.020）の主張が止まる（中国語は正解を失う）。トルコ語（20/20 が `medial`、誤答）は止まらない（P ≈ 0）。トルコ語の誤りは、票の散らばりではなく、アラインメントの系統的な誤りによる。

## 評価

### 合成言語

R1 が実際に働くように、対訳の割合を **25%** にした LEVEL A を使う（対訳 5% では、3 つの位置がそろう票が 1〜4 票しかなく、R1 がほとんど働かない）。対訳 5% の LEVEL A も、回帰の確認として測る。

- 開発: シード 0〜19 × 3 系統。
- 評価（採用の判定の後に 1 回だけ）: シード **500〜519** × 3 系統（これまでどの版にも使っていない）。
- それぞれ、通常の対訳と、対訳を入れ替えた対照（`synthetic-mismatch-{系統}-{シード}`）。

### 実在言語（既知データでの確認。独立の検証ではない）

PUD の 19 言語（`PREREG_REAL_PARALLEL.md`・`PREREG_v1.6_ALIGNMENT_NULL.md` の対象）。100% の対訳と、ずらした対訳。正解は `PREREG_v1.7_VERB_RELATIVE.md` の定義。

**この 19 言語は、v1.7.0 で結果を見た**。B1 の効果は上に書いたとおり、ほぼ事前に分かる。新しい対訳つきの実在言語のデータは、手元にない。この確認は、独立の評価として数えない。

### 採用の基準（合成言語の開発シード）

- **A（誤答を増やさない）**: 対訳 25% と 5% のそれぞれで、v1.8.0 の動詞の位置の誤答が v1.7.0 以下。
- **B（正解の維持）**: 対訳 25% で、v1.8.0 の動詞の位置の正解が v1.7.0 の 90% 以上。
- **C（対照）**: 対訳 25% の入れ替えた対照で、v1.8.0 の主張（動詞の位置・主語と目的語・形容詞と名詞の順序のいずれか）が出た実行が、60 件中 6 件以下。

A・B・C のいずれかが不合格なら、評価に進まず、`v18_gates` の既定を False にして、結果を記録する。

### 報告するもの（合否は付けない）

- 合成言語の評価シードでの、v1.7.0 と v1.8.0 の正解・誤答・保留。
- PUD の 19 言語での、v1.7.0 と v1.8.0 の正解・誤答・保留（既知データ）。

## やらないこと

- 1/3・0.05/3・25%・90%・6 件 などの閾値を、結果を見て変えない。
- 結果を見て解読器を調整しない。

## 限界（事前に書く）

- B1 は、アラインメントの系統的な誤り（トルコ語のように、誤った票がそろう場合）を止めない。
- 実在言語の新しい評価データがないので、実在言語での効果は、既知データでの確認にとどまる。
- 票が少ない言語では、正しい主張も止まる（中国語の 6/8 など）。
