# 事前登録: v1.4 接辞の関門の多重検定補正

この文書は、実装と測定の**前に**コミットする。採用の基準はここに書いたものだけを使い、結果を見てから変えない。

## 背景

v1.3.0 の評価シード 200〜219 で、無作為な音節列の対照（syllable）の構造主張が 0.15 件/実行になり、事前登録の主基準（0.05 以下）を超えた（問題記録 #92）。

原因の推定: G1' は接尾辞側と接頭辞側をそれぞれ p ≤ 0.05 で検定し、**どちらか**が有意なら接辞の位置を主張する。2つの検定がほぼ独立なら、族の偽陽性率は 1 − 0.95² ≈ 0.0975 になる。

v1.3 の主基準にも問題があった。対照 20 回で「0.05 件/実行以下」は「20 回中 1 回まで」と同じで、偽陽性率がちょうど 5% の正しい検定でも 26% の確率で不合格になる。評価として検出力が低い。

## 変更

- **G1'（v1.4）**: 接尾辞側・接頭辞側の検定の有意水準を、それぞれ 0.05 から **0.025** に下げる（Bonferroni 補正。族の水準 0.05）。統計量・対照の作り方・置換回数（199 回）は v1.3 と同じ。
- 設定 `affix_null_alpha`（既定 0.025）で切り替える。`affix_null_alpha: 0.05` で v1.3.0 と同じ出力、`null_gates: False` で v1.2.0 と同じ出力になることをテストで確かめる。
- 他の関門（G2・G3・G4'）は変えない。

置換 p 値の最小値は 1/200 = 0.005 なので、0.025 は判定できる範囲にある。

## 測定

- 開発: 実コーパスは開発シード 0〜19（3系統 × LEVEL A・C × 単語境界あり・なし）。対照（random・shuffled・syllable）は**シード 0〜99 の 100 回ずつ**。
- 評価（採用の判定の後に1回だけ）: 実コーパスはシード **300〜319**、対照はシード **300〜399**。どちらもこれまでどの版の調整・評価にも使っていない。v1.3 の評価シード 200〜219 は、結果を見たので v1.4 の判定に使わない。
- 比べる版: v1.2.0（`null_gates: False`）、v1.3.0（`affix_null_alpha: 0.05`）、v1.4.0（既定）。

## 採用の基準

対照の種類ごとに、構造の主張（保留でない項目が1つ以上）が出た実行の数を数える。

- **主基準**: 3種類の対照のそれぞれで、100 回中 **8 回以下**。
  - 本当の偽陽性率が 5% なら合格の確率は 0.94、10% なら 0.32、15% なら 0.03（二項分布）。
- **副基準（実コーパス）**: 単語境界ありの文章で、v1.3.0 と比べて構造の誤答が増えず、正解の減少が 5% 以内。単語境界なしの文章は、G4' で接辞の位置を常に保留しているので比較しない。
- 判定は開発シードで行う。開発で合格したときだけ評価を1回実行し、結果を合否にかかわらず記録する。評価で主基準を満たさなくても、閾値は変えない。
- 各対照について、主張が出た割合の 95% 信頼区間（Clopper–Pearson）を併記する。

## やらないこと

- 0.025・199 回・「8 回以下」を、結果を見て調整しない。
- 外部コーパスを判定に使わない（外部の無作為対照は v1.3 の設計に使ったため）。

## 判定（開発: 実コーパス 0〜19、対照 0〜99。`results/gates/gates-dev14.json`）

対照で構造の主張が出た実行の数（100 回中）と 95% 信頼区間:

| 対照 | v1.2.0 | v1.3.0 | v1.4.0 |
|---|---|---|---|
| random | 2 [0.002, 0.070] | 0 [0, 0.036] | 0 [0, 0.036] |
| shuffled | 100 [0.964, 1] | 2 [0.002, 0.070] | 0 [0, 0.036] |
| syllable | 100 [0.964, 1] | 8 [0.035, 0.152] | **3 [0.006, 0.085]** |

実コーパスの構造の判定（正解 / 誤答 / 保留）: 単語境界あり 439 / 7 / 274、単語境界なし 27 / 6 / 687。v1.3.0 と v1.4.0 で同一。

- 主基準: **合格**（3種類とも 8 回以下）。
- 副基準: **合格**（v1.3.0 と比べて変化なし）。
- v1.3.0 も開発では syllable 8/100 で、この基準の境界にあった。評価シードへ進む。

## 評価（1回だけの実行: 実コーパス 300〜319、対照 300〜399。`results/gates/gates-eval14.json`）

| 対照 | v1.2.0 | v1.3.0 | v1.4.0 |
|---|---|---|---|
| random | 1 [0.000, 0.055] | 0 [0, 0.036] | 0 [0, 0.036] |
| shuffled | 100 [0.964, 1] | 8 [0.035, 0.152] | 3 [0.006, 0.085] |
| syllable | 100 [0.964, 1] | 9 [0.042, 0.164] | **5 [0.016, 0.113]** |

実コーパス（正解 / 誤答 / 保留）: 単語境界あり 453 / 5 / 262、単語境界なし 22 / 4 / 694。v1.3.0 と v1.4.0 で同一。

- 主基準: v1.4.0 は **合格**（3種類とも 8 回以下）。同じ基準で、v1.3.0 は syllable が 9 回で不合格になる。
- 副基準: **合格**（v1.3.0 と比べて変化なし）。
- syllable の開発と評価の合計: v1.3.0 は 17/200 = 8.5%、v1.4.0 は 8/200 = 4.0%。v1.3.0 の値は、2つの独立な検定から予想される族の偽陽性率 ≈ 9.75% に近い。v1.4.0 は名目の 5% 以下に収まった。
- 注意: shuffled 対照は語の内部の接辞が本物なので、この対照での接辞の主張は誤りとは言えない（問題記録 #93）。v1.4.0 の shuffled 3 回は、偽陽性ではなく「文脈との連動が壊れたあとに残った、本物の接辞の検出」の可能性がある。
