## 10. 研究上の限界

- 生成器と解読器を同じAIが設計した。解読器の事前仮定（接辞は閉じたクラス、会計文書に合計行がある、対訳は役割つきの構造で与えられる等）は生成器の設計と一致しており、内部テストの成績は完全な未知言語への一般化を証明しない。
- 独立初見テストの得点は、対象のコーパスと初回予測時の解読器の版に限って解釈する。同じAIが解読器凍結後に作った第4系統は「準初見」であり、独立テストの代わりにはならない。
- LEVEL C で意味の過剰主張が0件なのは、解読器に意味ラベルの供給源がないという構造上の帰結である。「主張を我慢できた」ことの証明としては弱い。
- LEVEL C の数詞の値は「最小の単位を1とする」仮定つきの相対値である。合計行のないコーパスでは、対訳の数量があればその一部だけを解き（v1.1）、対訳もなければ判定不能になる。
- 意味の正解は生成器の概念語彙（約150概念）との一致で測っている。実在言語の多義性・比喩・文脈依存は再現していない。同音異義語は語義の区別をせず、頻度の高い方を答える。
- 主語と目的語の順序、形容詞と名詞の順序は、役割の分かる対訳がなければ判定不能と報告する（LEVEL B・C では常に未回答）。
- 不規則動詞（補充形）は規則形と結び付けられない。SOT の「数詞の後は属格複数」という規則は、格語尾の機能推定を誤らせる。
- 単語境界のない連続書記では、全文書をまとめて分割する（train と held-out を分けていない）。
- 解読器の閾値（主張の閾値0.5、接辞の妥当性条件など）は開発シード0〜4で調整した。評価シード100〜119は最終実行まで使っていない。
- 外部LLM・有料APIは使っていない。Python 標準ライブラリのみ。実験は GitHub Actions とローカルコンテナの両方で実行し、出力ハッシュを比較する。
- v1.1 で、数詞について新しい仮定を加えた: 位取りの単位（十・二十など）は、それに掛けられる語の値より大きい。多くの人間の数詞体系に当てはまるが、例外を持つ言語では誤る。
- 単語境界のない文章の既定の分割はトランスダクティブ（評価用の文書の文字列も分割の学習に使う）。正解は使っていないが、train だけで学習する評価ではない。インダクティブ方式の結果は E9 に別の指標として載せている。
- 同じ概念が1つの文に複数の役割で出る場合、格接辞で役割が絞れなければ、その語を語順の推定に使わない。格接辞のない言語では、この種の文から語順の証拠を得られない。
- 外部コーパスの採点方式は v1.2.0 で方式2に変えた（既知語を推定した語から除く）。方式1の記録は残してあり、報告書に並べて表示している。
- 単語境界のない文章では、分割の誤りのため構造の推定で誤答が正解より多かった（問題記録 #34）。v1.3 以降は、単語境界のない文章では動詞の位置と接辞の側を常に保留する（誤答とともに正解も失う）。
- 実在言語（UD r2.15 を換字、10 言語）の評価では、対訳なしの動詞の位置の主張は妥当でなかった。動詞とみなしたクラスの大半が動詞ではなく、正解は偶然の一致だった（問題記録 #94）。接辞の側は 8 正解・0 誤答・2 保留だった。
- v1.5.0 は、対訳による証拠がなければ動詞の位置を主張しない。合成言語の LEVEL B・C で正解を 110 件失い、実在言語ではポーランド語の本物の動詞のクラスも保留にする（問題記録 #94・#98）。動詞のクラスが動詞かどうかを意味なしで確かめる方法は、まだ無い。
- 評価シード 200〜219 は、v1.1 の最終報告に加えて、v1.3 の関門の評価（1回）と v1.5 の報告書の再実行にも使った。関門の設計と閾値は開発シードだけで決め、評価の結果を見て調整していない（docs/PREREG_v1.3_NULL_GATES.md）。v1.4 の評価には新しいシード 300〜399 を使った。
- 対訳つきの実在言語（PUD、14 言語）の評価では、動詞の位置の主張が対訳の正しさに依存せず（問題記録 #100）、正解の分布に偏りがあって単純な方法と区別できなかった（#101）。対訳があれば実在言語でも語順を当てられる、とはまだ言えない。
- v1.6.0 は、対訳を入れ替えた対照と区別できない語順の主張を保留にする。合成言語の LEVEL A で正解の約 1 割（動詞の位置）を失い、実在言語では動詞の位置をほとんど主張しない。主語と目的語の順序は対訳があれば主張するが、実在言語の評価では正解がすべて SO で、単純な方法と区別できていない（#101）。
- v1.7.0 は、対訳があれば動詞の位置を主語・目的語との前後関係で数える。v1.8.0 は、最多の値の二項検定を要求し、実在言語（PUD の 19 言語、既知データ）では 2 正解・0 誤答・17 保留になった。実在言語で動詞の位置を言い当てられるとは、まだ言えない（問題記録 #102）。対訳をずらしたときの主張は出さない。
