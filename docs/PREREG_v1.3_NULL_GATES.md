# 事前登録: v1.3 帰無対照の関門（null gates）

この文書は、実装と開発シードでの測定の**前に**コミットする。採用の基準はここに書いたものだけを使い、結果を見てから変えない。変えた場合は、変えたことと理由を報告書と問題記録に残す。

## 背景（なぜ変えるか）

外部・内部の記録で、無作為データや根拠の弱い条件に対して構造の主張が出ている。

1. `gpt6-random-control-20261114`（無作為の語列）で、接辞の位置を `both`（信頼度 0.5）と主張した。形態の検定も `present: true`（接辞付きの割合 1.0、接辞 32 種）。
2. 内部の無作為対照（E7_null）は `verb_position` と `numeral_base` しか数えておらず、接辞の位置の主張を見ていなかった。上の誤りが内部で見えなかった理由。
3. 統語検定はシャッフル 6 回の z で判定しており、無作為の記号列で「統語あり」と出ることがある（問題記録 #40）。
4. 単語境界のない文章では、構造の判定で誤答が正解より多い（問題記録 #34）。

## 変更（4つの関門）

すべて設定 `null_gates`（既定 True）で切り替える。False で v1.2.0 と同じ出力になること（構造・語彙・数詞）をテストで確かめる。

- **G1 形態の帰無対照**: 語形の各位置の文字を、同じ長さの語形の間で位置ごとに独立に並べ替えた対照語彙を 99 個作る（各位置の文字の分布と語の頻度は保つ。語幹と接辞の結び付きは壊す）。接尾辞側・接頭辞側それぞれ、解析された延べ数が対照の 95% を超えない側（置換 p > 0.05）は、接辞の付く側の根拠から外す。両側とも外れたら `affix_position` は保留、形態の検定は `present: false`。形態素解析そのもの（語幹の切り出し）は変えない。
- **G2 統語検定の置換 p 値**: シャッフルを 6 回から 199 回にし、条件付きエントロピーが対照以下になる割合で p 値を出す。`present` は p ≤ 0.01 かつ減少率 > 0.03。z は参考として残す。
- **G3 語順の主張は統語ありが前提**: G2 で統語なしなら、`verb_position`・`so_order`・`adj_noun`・`num_noun` を保留にする。
- **G4 単語境界のない文章の分割安定性**: 既定の分割（unigram）に加え、遷移確率の分割（transition）でも解読器を当てる。`verb_position` と `affix_position` は、2つの分割で値が一致したときだけ主張する（一致しなければ保留）。

## 測定（開発シードのみ）

- シード: 開発シード 0〜19。評価シード 200〜219 は採用の判定に使わない（採用後に1回だけ実行し、結果を記録する）。
- 実コーパス: 3系統（KES・UMB・SOT）× LEVEL A・C × 単語境界あり・なし。
- 対照: `null_corpus` の random・shuffled に加え、外部の無作為対照に似た「音節を無作為に並べた固定長の語」（syllable）。
- 指標: 構造の各項目（`verb_position`, `so_order`, `affix_position`, `numeral_base`, `adj_noun`, `num_noun`）の 正解・誤答・保留 の件数。対照では、保留でない構造の主張（全項目）の件数。

## 採用の基準

- **主基準**: 対照（random・shuffled・syllable、各 20 実行）で、保留でない構造の主張が実行あたり平均 0.05 件以下。
- **副基準1（単語境界あり）**: 実コーパスの構造の誤答の合計が増えない。正解の合計の減少は 5% 以内。
- **副基準2（単語境界なし）**: G4 適用後に、構造の正解が誤答より多い。満たさなければ G4 の代わりに **G4'**（単語境界のない文章では `verb_position` と `affix_position` を常に保留）を採用する。G4' は誤答を 0 にする代わりに正解も 0 にすることを、報告書に明記する。
- G1〜G3 は個別に評価し、主基準に寄与せず副基準1を破る関門は採用しない。

## やらないこと

- 閾値（p ≤ 0.05、p ≤ 0.01、減少率 0.03、対照 99・199 回）を測定結果を見て調整しない。
- 外部コーパス（答えが公開済みのもの）を採用の判定に使わない。外部コーパスは採用後の参考値として記録するだけ（答えが公開済みなので独立の検証にはならない）。
